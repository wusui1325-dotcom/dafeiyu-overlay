# 大肥魚 DaFeiYu Overlay

基於 **DeepSeek API (BYOK)** 的純本地無後端 Android 懸浮輔助應用，採用**現代黑白平面流線體 UI** 設計，每個項目與按鈕皆配有極簡圖示。

## 核心特色

- **無後端・BYOK 架構**：零中繼伺服器，API Key 透過 Android Keystore (`EncryptedSharedPreferences`) 加密儲存在本機，直接呼叫 `https://api.deepseek.com`（支援自訂 OpenAI 相容 Base URL）。
- **原生視覺截圖支援**：預設採用 `deepseek-flash` 模型，並支援透過 `/models` 一鍵拉取最新可用模型、調整 `Temperature`、`Max Tokens` 與 `Reasoning Effort`。
- **現代黑白平面流線體 UI**：支援純粹白 / 極簡黑雙單色主題、1dp 細邊框平卡片、流線膠囊導覽列，每個項目與按鈕皆配有清晰圖示。
- **初始化引導精靈**：初次啟動自動進入引導流程（設定 BYOK、模型參數、權限檢查），隨時可於首頁手動重新觸發。
- **高自由度自定義**：即時調整懸浮球大小 (`36dp–84dp`)、透明度 (`20%–100%`)、座標位置與自動貼邊吸附、黑白懸浮風格、截圖隱藏延遲、多選點擊間隔與系統提示詞。

## 「大肥魚」核心流程

在任何其他應用程式畫面中，點擊懸浮球即可喚起模式選單：

### 1. 輸入類 (Input Mode)
1. 選擇「輸入類」，手動點擊一次目標輸入框位置。
2. 系統自動隱藏所有懸浮視窗並立即截圖（確保截圖乾淨無遮擋），送至 DeepSeek 視覺模型。
3. 模型僅輸出應填入輸入框的精簡內容，系統隨即透過無障礙服務（或剪貼簿貼上 / Shizuku 備援）直接寫入該輸入框。

### 2. 選擇類 (Choice Mode)
1. 選擇「選擇類」，彈出流線快捷小窗：可手動 `[-]` / `[+]` 增減選項數量，或直接點擊快捷按鈕 **`2`** / **`4`**。
2. 按下確定後，系統立即隱藏懸浮窗並截圖發送 DeepSeek，**同時**引導您依「從上往下、從左往右」順序點擊各選項位置。
3. 模型依相同順序回傳單選或多選編號（如 `2` 或 `1,3`），系統在您點完座標後自動依序點擊正確選項。

## 權限說明

| 權限 | 用途 | 是否必備 |
| --- | --- | --- |
| 懸浮視窗 (`SYSTEM_ALERT_WINDOW`) | 顯示大肥魚懸浮球、選單、快捷數量窗與座標標記 | 必備 |
| 無障礙服務 (`AccessibilityService`) | Android 11+ 免錄屏彈窗截圖、模擬點擊與文字注入 | 必備 |
| 通知權限 (`POST_NOTIFICATIONS`) | 常駐前景服務通知與快捷顯示/隱藏按鈕 | 建議 |
| 忽略電池優化 | 避免背景運行時被系統回收 | 建議 |
| Shizuku | 提供 Shell 備援輸入，不開啟亦可完整運作 | 選用 |

## 建置方式

本專案已配置 GitHub Actions (`.github/workflows/android-build.yml`)，每次推送至 `main` 分支皆會自動編譯並上傳 Debug APK Artifact。

本地建置（需 JDK 17 與 Android SDK 35）：
```bash
gradle assembleDebug
```
